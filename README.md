# 🍑 КБЖУ-бот для Telegram — учёт питания по фото

Telegram-бот для совместного учёта питания в групповом чате с темами. Кидаешь фото тарелки на кухонных весах — бот распознаёт блюдо, читает вес с дисплея, считает КБЖУ и записывает в Google-таблицу. Полностью бесплатный стек: Google Apps Script (хостинг) + Gemini API (распознавание) + Google Sheets (база).

## Возможности

- 📸 **Фото тарелки на весах** — определяет блюдо и вес с дисплея одним снимком
- 📸 **Фото этикетки** — читает таблицу КБЖУ и массу нетто с упаковки
- ✍️ **Текст в свободной форме** — «гречка 200 г», «2 тоста, слайс сыра, 6 черри»
- ❓ **Уточняющие вопросы с памятью** — если не хватает данных, задаёт один вопрос; ответ «300» или «не знаю, прикинь» связывается с исходным фото (кэш 30 минут)
- 👥 **Несколько пользователей** — различает участников чата, у каждого свой учёт и своя норма
- 🎯 **Норма КБЖУ** — вручную (`/норма 1600`) или расчёт по мини-анкете (формула Миффлина—Сан-Жеора, мягкий дефицит 15%)
- 🌙 **Вечерняя авто-сводка** — итоги дня по всем участникам + короткий нейтральный разбор рациона от ИИ
- 🔇 **Работает только в одной теме** форум-чата, в остальные не лезет и не «коучит» без запроса

## Стек и почему он бесплатный

| Компонент | Роль | Стоимость |
|---|---|---|
| Telegram Bot API | интерфейс | бесплатно |
| Google Apps Script | сервер (вебхук, логика, триггеры) | бесплатно |
| Google Sheets | база данных | бесплатно |
| Gemini API (free tier) | распознавание фото и анализ | бесплатно, лимитов хватает с большим запасом: 2 человека тратят ~20–30 запросов/день |

## Структура Google-таблицы

Создай таблицу с двумя листами:

**Лист «Лог»** — заголовки в первой строке:

| Дата | Время | Кто | Блюдо | Вес, г | Ккал | Белки | Жиры | Углеводы |
|---|---|---|---|---|---|---|---|---|

**Лист «Настройки»** — заголовки в первой строке:

| user_id | Имя | Норма ккал | Норма Б | Норма Ж | Норма У |
|---|---|---|---|---|---|

`user_id` — внутренние номера Telegram-аккаунтов участников (как их узнать — в шаге 6). Нормы можно оставить пустыми: заполнятся командой `/норма`.

Лист «Debug» бот создаст сам — туда пишутся ошибки.

## Установка

### 1. Google-таблица

Создай таблицу по структуре выше. Из адресной строки скопируй **ID таблицы** — строку между `/d/` и `/edit`:
`https://docs.google.com/spreadsheets/d/`**`ЭТО_ID`**`/edit`

Проверь часовой пояс таблицы: **Файл → Настройки → Часовой пояс** — поставь свой. Это важно для корректного подсчёта сумм по дням.

### 2. Бот в BotFather

1. В Telegram найди **@BotFather** (с галочкой верификации).
2. `/newbot` → имя → уникальный username, оканчивающийся на `bot`.
3. Сохрани **токен** (строка вида `123456789:AA...`). Никому не показывай.
4. **Обязательно:** `/setprivacy` → выбери бота → **Disable**. Без этого бот в группе не видит обычные сообщения и фото — только команды.
5. `/setjoingroups` → выбери бота → **Enable** (обычно так по умолчанию).
6. Опционально, для красивого меню команд: `/setcommands` → выбери бота → отправь:
   ```
   day - Сводка за сегодня
   week - Итоги за 7 дней
   del - Удалить последнюю запись
   norm - Норма: задать или рассчитать
   cancel - Сбросить вопрос/анкету
   help - Шпаргалка
   ```
   (Telegram подсказывает только латинские команды; русские алиасы `/день`, `/неделя` и т.д. работают параллельно.)

### 3. Ключ Gemini

1. Зайди на [aistudio.google.com](https://aistudio.google.com) → **Get API key** → **Create API key**.
2. Если AI Studio не может сам создать проект («Unable to create API key») — создай проект руками: [console.cloud.google.com](https://console.cloud.google.com) → прими Terms of Service → выпадашка проектов → **New project** → затем в AI Studio: Create API key → **Import project**.
3. Сохрани ключ (`AIzaSy...`). Карту привязывать не нужно — без неё ты гарантированно на бесплатном тире.

⚠️ **Известная проблема:** ошибка `403 PERMISSION_DENIED: Your project has been denied access` встречается массово даже на свежих аккаунтах — Google флагует проекты внутренним фильтром. Самое быстрое решение — создать ключ с другого Google-аккаунта (для бота нужен один ключ, неважно чей).

### 4. Скрипт

1. Открой таблицу → **Расширения → Apps Script**. Если видишь «Не удалось открыть файл» — в браузере несколько Google-аккаунтов конфликтуют; открой таблицу в окне инкогнито под одним нужным аккаунтом.
2. Удали заготовку, вставь содержимое `Code.gs` из этого репозитория.
3. Заполни блок НАСТРОЙКИ в начале файла:
   - `BOT_TOKEN` — токен от BotFather
   - `GEMINI_KEY` — ключ из AI Studio
   - `SHEET_ID` — ID таблицы
   - `TOPIC_ID` и `CHAT_ID` — узнаем в шаге 6, пока оставь как есть
   - `TZ` — свой часовой пояс (например `Europe/Belgrade`, `Europe/Moscow`)
4. Сохрани (Ctrl+S), назови проект.

### 5. Публикация и вебхук

1. **Начать развёртывание → Новое развёртывание** → тип **Веб-приложение**:
   - Запуск от имени: **От моего имени**
   - Доступ: **Все** (это нужно, чтобы сервер Telegram мог стучаться; адрес — длинная случайная строка, подобрать её нельзя)
2. Разреши доступы. Окно «Приложение не проверено» — это твой же скрипт: **Дополнительные настройки → Перейти → Разрешить**.
3. Скопируй **URL веб-приложения** (заканчивается на `/exec`).
4. Собери в блокноте ссылку и открой её в браузере:
   ```
   https://api.telegram.org/bot<ТОКЕН>/setWebhook?url=<URL_СКРИПТА>
   ```
   Не потеряй `?` между `setWebhook` и `url=`. Ответ должен быть `{"ok":true,...,"description":"Webhook was set"}`.

### 6. Узнаём TOPIC_ID и CHAT_ID

1. Временно добавь в начало `doPost` (сразу после строки `const update = ...`):
   ```javascript
   debugLog('Пришло: ' + e.postData.contents.slice(0, 300));
   ```
2. Обнови версию (см. «Важно про обновления» ниже), добавь бота в чат и сделай его **администратором** (в форум-группах так надёжнее всего).
3. Напиши что-нибудь в нужной теме. В листе Debug появится сырое сообщение — найди в нём:
   - `"message_thread_id": N` → это **TOPIC_ID**
   - `"chat":{"id": -100...}` → это **CHAT_ID**
   - `"from":{"id": ...}` → это **user_id** участника для листа «Настройки»
4. Впиши значения в НАСТРОЙКИ, удали временную строку с debugLog, обнови версию.

### 7. Вечерняя сводка

1. В редакторе выбери в выпадашке функцию **setupTrigger** → **Выполнить** (один раз; разреши доступ к триггерам). Создастся ежедневный триггер на ~21:00.
2. Время триггера считается по часовому поясу **проекта**: ⚙️ Настройки проекта → Часовой пояс → поставь свой.

### ⚠️ Важно про обновления кода

После **любого** изменения кода Telegram продолжает говорить со старой версией, пока ты не сделаешь:
**Начать развёртывание → Управление развёртываниями → ✏️ → Версия: «Новая версия» → Начать развёртывание.**
URL при этом не меняется, вебхук перенастраивать не нужно. Если случайно создать «Новое развёртывание» вместо обновления — появится второй URL, и вебхук будет смотреть в пустоту.

## Команды

| Команда | Что делает |
|---|---|
| `/день` (`/day`) | сводка за сегодня по всем участникам |
| `/неделя` (`/week`) | итоги за 7 дней |
| `/удали` (`/del`) | удалить свою последнюю запись |
| `/норма 1600` (`/norm`) | задать норму вручную; можно с БЖУ: `/норма 1600 120 50 150` |
| `/норма расчёт` | расчёт нормы по анкете (пол, возраст, рост, вес, активность, цель) |
| `/отмена` (`/cancel`) | сбросить вопрос бота или анкету |
| `/помощь` (`/help`) | шпаргалка |

## Траблшутинг

| Симптом | Причина и решение |
|---|---|
| Бот молчит совсем | Проверь `getWebhookInfo` (ссылка по аналогии с setWebhook): совпадает ли `url` с активным развёртыванием? Нет ли двух развёртываний? |
| Молчит, в «Выполнениях» есть doPost со статусом «завершено» | Скорее всего, фильтр темы: неверный `TOPIC_ID`, или скрипту не хватает разрешений — запусти любую функцию вручную, раздай доступы |
| «Выполнения» есть, Debug пуст, ответа нет | Скрипт падает до первой записи: запусти вручную тестовую функцию, которая пишет в таблицу, — увидишь ошибку прямо в журнале |
| `403 Your project has been denied access` | Флаг Google на проекте/аккаунте — создай ключ с другого аккаунта |
| `404 model is no longer available` | Имена моделей устарели — в коде используются «плавающие» `gemini-flash-latest`; список доступных моделей можно получить запросом `GET /v1beta/models?key=...` |
| Сумма «за сегодня» всегда 0 или равна последней еде | Часовой пояс таблицы не совпадает с поясом скрипта: даты «уезжают» на день. В коде это уже починено (даты пишутся текстом с апострофом), но проверь пояс таблицы: Файл → Настройки |
| Ответ бота «не смогла разобрать», в Debug «вернул не-JSON» | Модель обернула ответ лишним текстом — в коде уже стоит склейка всех частей ответа и чистка markdown-кавычек |

## Безопасность

- **Никогда не коммить реальные токены.** В `Code.gs` в репозитории — только плейсхолдеры; реальные значения живут только в твоём Apps Script.
- Если токен засветился — BotFather → `/revoke` → новый токен → в скрипт → новая версия → заново `setWebhook`. Ключ Gemini пересоздаётся в AI Studio в два клика.
- Помни: на бесплатном тире Gemini запросы могут использоваться Google для обучения моделей. Для фото еды это обычно приемлемо — но знать стоит.

## Точность

Оценка КБЖУ по фото — это оценка: простые продукты и этикетки распознаются хорошо, составные блюда — с погрешностью до ±30% (модель не видит масло в плове). Для отслеживания тренда при стабильном ведении этого достаточно; для медицинских задач — нет. Бот — инструмент учёта, а не замена консультации специалиста по питанию.
